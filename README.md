# Introducción

Este proyecto tiene como objetivo aplicar análisis estadístico reproducible utilizando RStudio y GitHub. 
Se trabajó con una base de datos obtenida de OpenIntro para analizar si existe una diferencia significativa en el peso de recién nacidos según el hábito de fumar de la madre.

# Pregunta de investigación
¿Existe una diferencia significativa en el peso promedio de los bebés recien nacidos entre madres fumadoras y no fumadoras?

# Hipótesis estadísticas
## Hipótesis nula (H₀)
No existe diferencia significativa en el peso promedio de los bebés recien nacidos entre madres fumadoras y no fumadoras.
## Hipótesis alternativa (H₁)
Si existe diferencia significativa en el peso promedio de los bebés recien nacidos entre madres fumadoras y no fumadoras.

# Datos
## Fuente
Base de datos obtenida de OpenIntro.
## Tipo de t test utilizada
Se utilizó una prueba t de dos muestras independientes ( bilateral) porque se compararon los promedios de peso entre dos grupos distintos: madres fumadoras y no fumadoras. 

## Resultados
Se acepta la hipótesis nula, es decir, no hay evidencia estadísticamente significativa de una diferencia en el peso promedio de los bebés entre madres fumadoras y no fumadoras.
